## 2. Расчёт интеллектуальных усилий E (Метод Холстеда)

**Базовые показатели исходного кода:**
* Число уникальных операторов: `n1 = 34`
* Число уникальных операндов: `n2 = 48`
* Общее число операторов: `N1 = 175`
* Общее число операндов: `N2 = 160`

**Пошаговый расчёт метрик:**
1. **Словарь программы:** `n = n1 + n2 = 34 + 48 = 82`
2. **Длина программы:** `N = N1 + N2 = 175 + 160 = 335`
3. **Объём программы:** `V = N * log2(n) = 335 * log2(82) ≈ 2129.8`
4. **Сложность программы:** `D = (n1 / 2) * (N2 / n2) = (34 / 2) * (160 / 48) ≈ 56.67`
5. **Интеллектуальные усилия:** `E = V * D = 2129.8 * 56.67 ≈ 120 696`
